# 3D Gabor Patch - 両眼視差による立体視

React Three Fiberを使用した3Dガボールパッチの可視化アプリケーション。両眼視差（ステレオスコピック表示）により、立体的なガボールパッチを体験できます。

## 特徴

- **3Dガボールパッチ**: ガウス関数でエンベロープされた正弦波グレーティング
- **両眼視差**: 左右の目に異なる画像を表示してステレオスコピック効果を実現
- **リアルタイムアニメーション**: 動的に変化するガボールパッチ
- **インタラクティブなパラメータ調整**:
  - 空間周波数
  - ガウス標準偏差
  - グレーティングの向き
  - アニメーションのON/OFF
  - ステレオビューのON/OFF

## セットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```

## 使い方

1. 開発サーバーを起動後、ブラウザでアプリを開く
2. 左側のコントロールパネルでパラメータを調整
3. ステレオビューをONにすると、画面が左右に分割される
4. 平行法またはVRビューアーを使用して立体視が可能
5. マウスドラッグでカメラを回転、ホイールでズーム

## 立体視の方法

### 平行法
1. 画面から少し離れる
2. 視線を画面より遠くに向ける
3. 左右の画像が重なって見えるまで調整

### VRビューアー
- スマートフォン用のVRビューアー（Google Cardboardなど）を使用

## ガボールパッチとは

ガボールパッチは、視覚科学や心理物理学の研究で広く使用される視覚刺激です。ガウス関数でエンベロープされた正弦波グレーティングで、以下のような特性があります：

- **空間周波数**: グレーティングの細かさ
- **位相**: 波の位置
- **向き**: グレーティングの方向
- **標準偏差**: ガウスエンベロープの広がり

このアプリケーションでは、これらのパラメータをリアルタイムで調整し、3D空間での視覚効果を体験できます。
